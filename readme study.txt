# Smart Study Time Tracker

## About The Project

As a student, managing study time between different subjects can become difficult. I created this project to track study sessions and analyse how time is being spent on different subjects.

The program calculates study duration using start and end times, stores study records and provides simple analysis through reports and graphs.

---

## Features

- Add study sessions
- Calculate study duration automatically
- Store study history
- View records in a table format
- Search subject records
- Calculate total study hours
- Calculate average study time
- Find most studied subject
- Set weekly study goals
- Visualise study time using graphs

---

## Technologies Used

- Python
- Matplotlib
- File Handling
- Lists
- Dictionaries
- Functions
- Data Visualisation

---

## How It Works

For every study session, the user enters:

- Date
- Subject name
- Start time
- End time
- Study notes

The program calculates the total duration and stores the information in a text file.

The collected data is then used to generate simple reports and graphs.
